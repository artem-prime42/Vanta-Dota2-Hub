# VANTA Dota2 Hub

VANTA is an independent desktop app for managing Dota 2 mods, generating hero cosmetic loadouts, and organizing Hero Grids.

> VANTA is an unofficial community project and is not affiliated with Valve or Dota 2.

## Download

Download the latest version from [GitHub Releases](https://github.com/artem-prime42/Vanta-Dota2-Hub/releases/latest).

- **Windows:** download `VANTA-Setup-<version>.exe` and run the installer.
- **Linux:** download `VANTA-<version>.AppImage`, make it executable, and run it.

Older versions and release notes are available on the [releases page](https://github.com/artem-prime42/Vanta-Dota2-Hub/releases).

## Highlights

- Generate cosmetic loadouts locally from the installed Dota 2 files.
- Manage and reorder VPK mods.
- Preview heroes and organize Hero Grids.
- English and Russian interface.

VANTA requires a Dota 2 installation for applying mods and hero cosmetics. Close Dota 2 before installing or removing game modifications.

## Project status

This repository contains product information and downloadable releases. Application source code is maintained in a separate private repository.
